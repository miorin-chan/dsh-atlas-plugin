# Plan de mejora modular de plugins

Abre la página de plugins con un atajo,
reinstala plugins locales y prepara borradores de auditoría para las actualizaciones.
Alterna entre npm y repositorios locales para plugins y miembros directos de paquetes agrupados.
Puedes activar o desactivar cada función por separado.
