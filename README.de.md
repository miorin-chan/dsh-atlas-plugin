# Modularer Verbesserungsplan für Plugins

Öffnen Sie die Plugin-Seite per Tastenkürzel,
installieren Sie lokale Plugins neu und erstellen Sie Prüfentwürfe für Plugin-Updates.
Wechseln Sie für Plugins und direkte Mitglieder eines Bundles zwischen npm und lokalen Repositorys.
Jede Funktion lässt sich separat ein- und ausschalten.
