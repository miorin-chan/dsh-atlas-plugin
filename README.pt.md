# Plano de melhoria modular de plugins

Abra a página de plugins com um atalho, reinstale plugins locais e prepare rascunhos de auditoria para atualizações.
Alterne entre npm e repositórios locais para plugins e membros diretos de pacotes agregados.
Você pode ativar ou desativar cada função separadamente.
