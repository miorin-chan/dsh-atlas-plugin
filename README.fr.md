# Plan d’amélioration modulaire des extensions

Ouvrez la page des extensions avec un raccourci,
réinstallez des extensions locales et préparez des brouillons d’audit pour les mises à jour.
Basculez entre npm et des dépôts locaux pour les extensions et les membres directs d’un lot.
Chaque fonction peut être activée ou désactivée séparément.
