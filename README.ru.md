# План модульного улучшения плагинов

Открывайте страницу плагинов сочетанием клавиш,
переустанавливайте локальные плагины и готовьте черновики аудита обновлений.
Переключайте плагины и непосредственных участников сборки между npm и локальными репозиториями.
Каждую функцию можно включать и выключать отдельно.
